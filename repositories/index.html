Software

Selected open-source projects from my GitHub profile, including work with the Dynamic Legged Systems lab.

  • Quadruped-PyMPC

    Model predictive control for quadruped robots, with gradient-based (acados) and sampling-based (JAX) methods.

  • gym-quadruped

    A MuJoCo Gym environment for quadruped robot control.

  • morphosymm-rsl-rl

    An extension of RSL-RL using morphological symmetries in Isaac Lab.

  • basic-locomotion-isaaclab

    Quadrupedal locomotion in Isaac Lab, with sim-to-sim and sim-to-real pipelines.

  • Differential-Drive-Robot

    Path planning and control algorithms for a differential drive robot using ROS 2.

  • Self-Balancing-Robot

    Control algorithms for a self-balancing robot using ROS 2.
